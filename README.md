# zeta-providence

Proprietary software packages for the [Zeta](https://github.com/gretagen/zeta) package manager (Haliade OS).

## Repository layout

```
<package>/<package>-<version>.<deb|tar.gz|tar.xz>
```

Each package is referenced from the central registry at
[zeta-packages](https://github.com/gretagen/zeta-packages).
